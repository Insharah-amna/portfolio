# Professional Personal Portfolio Website

**Devixo Solutions – Web Development Internship – Task 01**

A modern, fully responsive personal portfolio built with only HTML5 and CSS3.

## Technologies Used
- HTML5 
- CSS3

## Website Features
- Sticky navigation bar with smooth scrolling and a CSS-only mobile menu
- Hero section with name, tagline, introduction, call-to-action buttons and profile image
- About, Skills (cards with progress bars), Education and Projects (3 project cards) sections
- Contact section with details and a contact form UI (no backend)
- Footer with name, quick links, social icons and copyright
- Hover animations on buttons, links, cards and social icons
- Responsive on desktop, laptop, tablet and mobile with no horizontal scrolling
- Keyboard focus styles and reduced-motion support

## Running the Website
1. Clone the repository: `git clone https://github.com/your-username/portfolio.git`
2. Open the `portfolio` folder.
3. Double-click `index.html` to open it in any modern browser.

No installation or build step is required.
